# e-plantShopping – Paradise Nursery Shopping Application

e-plantShopping is a React-based online plant shopping application for **Paradise Nursery**. Customers can browse a collection of plants, add plants to a shopping cart, change item quantities, remove items, and view the cart total.

## Project Features

- Paradise Nursery landing page with a **Get Started** button.
- About Us section describing Paradise Nursery.
- Plant product listing with product names, categories, descriptions, images, and prices.
- Add plants to the shopping cart.
- Redux Toolkit cart state management.
- Increase or decrease item quantities.
- Remove products from the shopping cart.
- Display the total shopping cart price.

## Main Project Files

- `README.md` – project name and description.
- `App.jsx` – main Paradise Nursery landing page.
- `App.css` – landing page styling and background image.
- `AboutUs.jsx` – company information.
- `CartSlice.jsx` – Redux reducers for adding, removing, and updating cart items.
- `ProductList.jsx` – plant product listing.
- `CartItem.jsx` – shopping cart page.

## Technologies Used

- React
- JavaScript (JSX)
- CSS
- Redux Toolkit
- React Redux

## Run Locally

1. Install the project dependencies using `npm install`.
2. Start the React development server using the start script configured in the project.
